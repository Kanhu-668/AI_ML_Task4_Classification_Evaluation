# AI/ML Task 4 – Classification Model Evaluation

This project demonstrates how to train, evaluate and compare multiple Machine Learning classification models using Python and Scikit-Learn.

## 📌 Project Objective
The goal of this project is to:
- Train multiple classification algorithms
- Evaluate their performance using proper metrics
- Compare models using cross-validation
- Understand which model performs best for the dataset

---

## 🧠 Models Used
The following ML models were implemented and evaluated:

- Logistic Regression
- Decision Tree Classifier
---

## 📊 Evaluation Metrics
We used multiple performance metrics:

- classification_report
- Confusion Matrix
- Cross Validation Score

These metrics help in selecting the best model for classification tasks.

---

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-Learn
- Jupyter Notebook
